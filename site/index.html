How it works

One click starts it all

The launch is the trigger. Pick a game, and everything you chose for it happens around it.

01 · Launch

Pick a game from the tray menu, the library or its own hotkey. It starts through its store's client, or directly.

02 · Set up

TrayTrigger notes how Windows is set, then applies the game's profile: power plan, HDR, GPU preference, CPU cores, DLSS Override. Your tools close or start; your script runs.

03 · Play

TrayTrigger stays a tray icon. Suspend a game with Ctrl+Alt+P for a cutscene you can't pause, or close it from the tray.

04 · Put back

When the game exits, every per-game setting goes back and is checked. Closed tools return, the launcher closes if you asked. After a crash, on the next start.

Every launch, on the record

See exactly what a launch did

Each game's Played row in Activity & History lists what the profile changed, what it skipped and why, the cores the game ran on, what your script said it did, and the tools it closed and started. How Activity & History works →

Too many launchers

Every store in one tray menu

  • Seven stores, one scan. Steam, GOG, EA, Epic, Ubisoft Connect, Xbox / PC Game Pass and Battle.net games arrive with their real titles and art. Drop any exe or shortcut for the rest.
  • A right-click, or Ctrl+Alt+T. Now Playing, Recent, Favorites and your categories in the tray menu; type a few letters and press Enter. Give any game its own launch hotkey.
  • Clients out of the way. Games still start through their store, so cloud saves and achievements work, but Steam, GOG Galaxy and Epic start in the background, and any launcher can close after the game.

Per-game setup

Each game gets its own setup

Chosen in the game's Edit Game window, applied when it launches, and reverted when it exits.

Ryzen X3D & Intel hybrid

The right cores for each game

Games landing on the wrong CCD, or a Process Lasso rule for every exe?

Set CPU Cores per game: the 3D V-Cache cores on a Ryzen X3D, the performance cores on an Intel hybrid CPU, or Auto to let TrayTrigger pick for your CPU. It uses Windows CPU Sets, not a hard affinity mask, and the game's Played row says where it ran.

HDR & OLED

HDR on for this game, off when you quit

HDR left on after a game, and a washed-out desktop?

Set HDR On for the games that do it well and Off for the ones that render it badly, or let the profile decide. Windows' HDR switches when the game launches and switches back when it exits. A display already in HDR is left alone.

Profiles & DLSS Override

Power, GPU and DLSS, set per game

Optimized uses your high-performance power plan and GPU, keeps an NVIDIA GPU at full clocks and stops Windows throttling the game, with opt-in HDR, Do Not Disturb and a frame cap just under your refresh rate. Aggressive adds scheduling priority, timer resolution and more. Each profile lists exactly what it will change.

NVIDIA DLSS Override runs a game on your driver's newer DLSS files without touching the game folder.

Sim racing, flight & companion apps

Your apps start with the game, and close after

  • Tools that start with your games. SimHub, CrewChief, TrackIR or Afterburner start when a game launches and close after the last one exits. One that was already running is left alone.
  • Tools closed for your games. Discord, OneDrive or a browser close just before the game and open again after it, unless you opened it yourself in the meantime.
  • On the record. The game's Played row lists which tools were closed, started, or left as they were.

Your own scripts

Missing a feature? Write it.

If PowerShell can do it, TrayTrigger can do it around any game. Your script runs just before the game starts and again after it exits, with the game's name, exe and minutes played handed to it, and what it did shows up on that game's row in Activity & History.

  • Start from a ready-made one. The TrayTrigger-Scripts catalogue switches your display's refresh rate for one game and back, changes an Afterburner profile, records with OBS, or backs up a save folder when you quit. Or press New script... in Edit Game for a template.
  • One script, many games. Per-game Script Arguments hand each game its own values: a save folder, a profile number, a refresh rate.
  • Tested before you trust it. Test Run shows exactly what the script saw and printed. Make the game wait for it, give it a timeout, or cancel the launch if it fails.
  • In its own words. A line starting TT: goes on the game's Played row and in the launch popup, so you see "saves backed up", not an exit code.
  • Yours, and in plain sight. Nothing runs until you attach a script. Scripts run as you, or as Administrator through Windows' own prompt when you choose it.

Stutter Check & Performance Tweaks

Find the stutter before you blame the game

Separate from per-game setup: these are system-wide, and stay until you undo them.

  • Stutter Check. The checks every "my game stutters" thread asks for, in one click: overlays, a browser holding video memory, a monitor below its fastest refresh rate, memory below its rated speed, games on a hard drive, and more. It reports; it changes nothing by itself.
  • Tweaks you can see and undo. Each row shows its real Windows state and what the setting does. Undo one, or use Undo Preset; bulk changes can create a System Restore point first.
  • Hardware Specs. Live CPU, RAM and GPU load, VRAM, displays and drives, with warnings like a GPU running on fewer PCIe lanes than it supports.

No surprises

What it changes, and what it doesn't

What goes back

Per-game settings go back when the game exits, and are checked. After a crash, on the next start.

System tweaks and whatever your scripts do stay until you undo them. Bulk changes can make a restore point first.

How it touches a game

CPU cores are set with Windows CPU Sets, not a hard affinity mask. Nothing is injected into a game and no driver is installed.

Suspend refuses games with a kernel anti-cheat. TrayTrigger runs as you; a few machine-wide tweaks ask for UAC.

Your privacy

No telemetry, no account. It goes online for game info and art, for update checks you can turn off, and for services you add your own key to.

FAQ

Can it get me banned?

TrayTrigger doesn't inject anything into a game or install a driver. It changes Windows settings around the game and sets its CPU cores and priority through the same Windows APIs Task Manager uses. Suspend, which pauses a game's process, refuses games with a kernel anti-cheat, because a game that stops answering its anti-cheat can be disconnected. No outside tool can promise what an anti-cheat will decide, so leave a competitive game's profile Off if you're unsure.

Does it need administrator access?

Not to run. A few tweaks write machine-wide settings and show a UAC prompt when you enable them. TrayTrigger never runs elevated by default.

Does it phone home?

No telemetry. Outbound calls are Steam's public API (metadata and artwork for games you add), SteamGridDB and RAWG (only if you enter your own key), NVIDIA's driver service (only when you press Check for Newer Driver on an NVIDIA GPU), and GitHub Releases (update checks, which you can turn off).

Is the download signed?

No. Releases are not code-signed, so Windows SmartScreen may warn the first time you run the installer. Releases are built by GitHub Actions from the public source and published with a SHA-256 checksum file. Verify a download with Get-FileHash in PowerShell and compare it to SHA256SUMS.txt on the release page, then choose More info and Run anyway. See the code signing section for details.

TrayTrigger doesn't do something I want. Now what?

If it's something to do before or after a game, a script can do it: TrayTrigger runs a PowerShell script of yours at launch and at exit, with the game's details handed in, and shows what it did on the game's row in Activity & History. Start with the TrayTrigger-Scripts catalogue, or New script... in Edit Game. For anything else, ask in Discussions.

Can I move TrayTrigger to a new PC?

Yes. Settings › Diagnostics & Storage › Backup & Restore saves your library, settings, tools, scripts and artwork to one .zip. Restore it on the new PC and TrayTrigger finds your games again through their launchers. Game saves aren't part of a backup.
