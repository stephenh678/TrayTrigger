These files are excerpts of pages on PCGamingWiki (https://www.pcgamingwiki.com), kept so the tests can read
real wikitext. Each *.wikitext file says on its first line which page it was cut from and when.

They contain only the templates TrayTrigger reads (the infobox, Video, Input, Audio, API, Network/Multiplayer,
Save game cloud syncing and Game data), as the wiki had them on 2026-10-17.

The text is the wiki's, shared under the Creative Commons Attribution-NonCommercial-ShareAlike 3.0 license
(https://creativecommons.org/licenses/by-nc-sa/3.0/), not under TrayTrigger's own license. They are used here
only as test data and are not part of the app.

golden.json is the list of facts a second, separately written reader found in these excerpts; the parser's
tests compare against it.
