# Filtering tools

The filter button sits beside the sort box on the Tools page, under the same filter icon the Library uses, and it works the same way. It narrows what the list shows without changing anything about your tools. Only the options differ, because a tool has different facts from a game.

## How it relates to the tabs and the filter box

- The category tabs are your own labels for your tools, and stay the primary cut. The filter works inside whichever tab is selected.
- The filter box is a text match on name, category and path.
- All three apply together. On the Utilities tab, with "vortex" typed and Runs as administrator ticked, you see the tools in Utilities with "vortex" in their name, category or path that run as administrator.

## What you can filter on

The flyout is in groups, each under a small blue heading.

**Kind** - Program, Script, Store app. Only the kinds you actually have are listed, and the group is left out while every tool is the same kind.

**TrayTrigger settings** - what TrayTrigger has been told to do for a tool.
- Favorite - the same set as the Favorites tab, here so you can combine it with the others.
- Has a hotkey, Runs as administrator, Hides its window.
- Starts with games and Closes for games - the tools in the game tabs, the ones you set up in Edit Tool. A script or Store app can't do either, so a box left ticked on one doesn't count.

**Needs attention** - File missing (a program that has moved, or a Store app that was uninstalled) and No icon.

## The opposite of a setting

The options in TrayTrigger settings are yes/no facts, so each has an opposite, as in the Library. Press one once to tick it, press it again and its label turns amber and changes to the opposite ("No hotkey", "Doesn't start with games"), and a third press clears it. "Favorite" with "No hotkey" shows the favorites that have no hotkey.

## How the ticks combine

- Within Kind and Needs attention, ticking two shows tools that match either. Within TrayTrigger settings, ticking two shows tools that match both.
- Across groups they are "and". Script plus Has a hotkey shows the scripts with a hotkey.
- A group with nothing ticked places no restriction.

## Saved filters

The Saved section at the top of the flyout keeps combinations you use again, exactly as in the Library: **Save current...** names the ticks on screen, pressing a saved filter puts its ticks on screen, the x beside it deletes it after asking, and a tick you change afterwards marks it "edited". Only the ticks are saved, not the category tab or the filter box. Saved filters are part of Backup & Restore.

## Clearing, and what the filter did

- **Clear**, at the top, resets every group. **clear** beside a group's heading resets just that group.
- Under the count at the top, the flyout says what the ticks did: "Showing 3 of 9" is 3 tools out of the 9 the current tab and filter box would show.
- The ticks are kept between sessions, so a filter you set stays on until you clear it. The button shows how many are on, and a list the filter has emptied says so and offers **Clear Filters**.
- Leaving the Tools page clears the filter box, but not the ticks.

The Library's filter is the same flyout; see Filtering the library.
