# Intel Application Optimization (APO)

## Why it matters

On Core Ultra processors, and the 14th-gen desktop K parts Intel added it to, Windows doesn't always put a game's threads on the best cores. Intel's Application Optimization watches the games Intel has profiled and steers their threads itself, and Intel's own figures and reviewers' tests show double-digit gains in those games. It does nothing for games that aren't on its list, and it is free.

## How to install it

1. Install the **Intel Dynamic Tuning Technology** driver from your motherboard or laptop maker's support page, or Intel's. APO needs it.
2. Install **Intel Application Optimization** from the Microsoft Store.
3. Open it once and turn on the games it lists. New games are added with its updates.

## Details

TrayTrigger looks for the installed Store app. A CPU that isn't one APO supports shows this check as not needed.
