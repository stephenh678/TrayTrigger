# Changelog

Notable, user-facing changes per stable release. The release workflow copies the matching
section into the GitHub Release as its **Highlights**, above the full commit list, so keep
each entry short and written for players, not for the git log.

Format: one `## x.y.z` heading per stable version (no `v` prefix), then a few bullets.
Pre-release builds (`-beta.N`, `-rc.N`) do not get their own section; they roll up into the
stable version they lead to.

## 1.5.1

- **Ryzen 7950X3D and 9950X3D games stay on the cache cores with the Ultimate power plan** - the plan held every core awake, which stops AMD's V-Cache driver from parking the cores without the extra cache, so any game you hadn't set CPU Cores for could land on them and run slower. On a Ryzen with 3D V-Cache on one of its two CCDs, the plan now leaves core parking as the Balanced plan has it and changes everything else as before, whether you use it all the time from the System page or only while a game runs.
- **NVIDIA Shader Cache: Unlimited** - a new System tweak. When the NVIDIA driver's shader cache is full it deletes the oldest shaders, and a game you come back to compiles them again while you play, with the hitches of a first run. Unlimited keeps them all. Restore Previous puts back the size you had, unless you've changed it since in the NVIDIA App or Control Panel. N/A on AMD and Intel.
- **Keep the DirectX Shader Cache** - a new System tweak that stops Storage Sense and Windows' automatic Disk Cleanup from deleting the DirectX shader cache, which makes every game rebuild its shaders and stutter as if it were the first run. You can still clear it yourself in Disk Cleanup.
- **Optimized keeps an NVIDIA GPU at full clocks** - a new Optimized tweak sets NVIDIA's power management mode to Prefer maximum performance while you play, so the GPU doesn't drop its clocks in lighter scenes and hitch when the action picks up again. It steadies the 1% lows rather than raising the average. It's set on the driver's Global profile, so Steam games get it too, and whatever you had goes back when the last game exits. On by default under Optimized, including for everyone upgrading; switch it off on the System page. NVIDIA only.
- **Optimized exempts the game from Windows' power throttling** - Windows can decide a game is in the background while you're still watching it, on a second monitor while you type in Discord or after a quick alt-tab, and slow it down or move it to an Intel CPU's efficiency cores. The game's process is now opted out, along with Windows 11 ignoring its timer requests while its window is hidden. On by default under Optimized.
- **A frame cap just under your refresh rate** - a new opt-in Optimized tweak for G-SYNC and FreeSync monitors caps the frame rate where NVIDIA Reflex would (138 fps at 144 Hz, 224 at 240 Hz), so every frame stays inside the variable refresh range without V-Sync's lag. It uses the primary display's refresh rate, leaves a Max Frame Rate you set yourself alone, and comes off when the last game exits. NVIDIA only.
- **Aggressive turns on Resizable BAR for the games NVIDIA never tested** - NVIDIA switches Resizable BAR on only for the roughly 60 games it has approved, and off for the ones it rejected, such as Final Fantasy XVI and Hogwarts Legacy. Every other game went without, though many gain from it. Aggressive now turns it on for those undecided games while you play, and NVIDIA's own decisions still win for the games it tested. It's skipped when Resizable BAR is off in the BIOS. If a game runs worse with it, move that game to Optimized. NVIDIA only.
- **Resizable BAR in Hardware Specs** - each dedicated GPU now says "Resizable BAR on", or, for a card that can use it (GeForce RTX 30 series, Radeon RX 5000 series or Intel Arc, and later), warns when it's off and names the two BIOS settings that turn it on (Above 4G Decoding and Re-Size BAR Support, called Smart Access Memory on AMD), which is worth a few percent on average and far more in some games.

## 1.5.0

- **Activity & History: what TrayTrigger did, and what didn't go to plan** — a bell at the bottom of the sidebar opens a new page. Needs Attention, at the top, shows only something wrong right now, with its fix: a setting a Performance Profile couldn't put back after a game, such as the power plan, marked CRITICAL, with Restore Previous to try again; once it works, the entry below gets a green FIXED badge. Below it, Recent lists the last 90 days in plain words: problems (a script that failed, a tool that didn't start or couldn't be closed, DLSS Override another app changed, a System tweak a Windows update changed back, a game still frozen after it couldn't be resumed, a data file that couldn't be read), changes TrayTrigger made and put back (each game's profile, System tweaks, settings put back after it closed unexpectedly) and every change to a performance setting (a game's profile, CPU Cores or DLSS Override, a tweak in Optimized or Aggressive, the profile new games get), and what happened in your library (each game you played and for how long, games you added, games the startup scan found, games no longer installed or installed again, an update installed). Each game you play is one row that moves to the top when you play it again, and the same problem happening again is one row with a count, and clicking a row shows each time, Show in log and Copy details. Each row has a badge in the System page's style - CRITICAL in solid red, PROBLEM, CHANGE and ACTIVITY - and tabs and a search box narrow it down. A red dot on the bell, a line in the tray icon's tooltip and a row in the tray menu say when something needs you. Nothing interrupts a game: one notification after the last game exits sums up anything that went wrong, and clicking it opens the page. Copy Diagnostic Info and Save Report include the recent problems.
- **Notify me when a scan finds new games** — a new setting under "Automatically scan on startup" for a notification when the startup scan finds games, so you hear about it even when TrayTrigger starts in the tray. Off by default.
- **A restore that doesn't take is noticed** — after a game, TrayTrigger now reads the power plan back, and checks HDR, Windows' multimedia scheduler settings, the speakers' mute and the Defender exclusion, instead of assuming each was put back.
- **The compact tray menu is on from the start** — tighter rows and smaller icons, so a long library fits without scrolling. It's on for a new install, and switched on once for everyone upgrading; untick "Compact tray menu" in Settings > Tray Menu for the roomier rows, and it stays off from then on. Reset to Defaults now turns it on.
- **Updates always come from TrayTrigger's own repository** — the editable "GitHub Repository (owner/repo)" box is gone from Settings > General > Updates. Changing it could only stop updates arriving or send About's links somewhere else; TrayTrigger now always checks stephenh678/TrayTrigger, and a value changed in an earlier version is ignored.

## 1.4.8

- **The free art and info keys, asked for up front** — the Welcome now starts by asking for the two optional keys, SteamGridDB for poster art and RAWG for info on games that aren't on Steam, before any game is added, because posters and info are fetched as each game is added. Since 1.4.6 a new install never mentioned them at all: the Welcome had dropped them, and the reminder upgraders get was skipped on a new install on the grounds that the Welcome covered them. Each key has a Get Free Key button that opens the site's key page, the SteamGridDB one now straight to the API page rather than your general preferences. TrayTrigger checks a pasted key with the site and says whether it works, or that the site turned it down, so a mistyped key no longer just means no art. Step two is Scan for Games, as before.
- **Keys in Settings work the same way** — pasting a key into Settings > Library & Art switches its source on, instead of the key box staying greyed out until you'd found and ticked the checkbox above it. Spaces and line breaks copied with a key are removed, and each key has a Check button and the same "Key works" line. Reset to Defaults keeps your keys switched on, where before it kept them but turned them off.
- **Tools is on from the start** — now that a tool can start with your games and close after them, the Tools page is part of playing rather than an extra, so it's switched on, for a new install and once for everyone upgrading. Don't want it? Untick "Enable Tools" in Settings > General and it stays off from then on. Reset to Defaults now turns it on rather than off. The Tools submenu in the tray menu is still off until you tick it in Settings > Tray Menu.
- **Hardware Specs that catch what slows a game down** — the Displays card names each monitor ("AW3425DW" rather than "Primary Monitor"), says whether HDR is on, and warns when a screen runs below the fastest refresh rate it offers at that resolution, like a 144 Hz monitor left at 60 Hz after a driver update or a new cable, with a button to Windows' display settings. The Graphics card lists every GPU, marked Dedicated or Built-in, so a laptop's two GPUs or a desktop with the processor's graphics on show both; AMD's built-in Radeon Graphics was counted as a dedicated card before. Each GPU has a live load reading and the video memory in use, from the same Windows counters Task Manager uses, beside the CPU's and memory's. On a Ryzen with 3D V-Cache on its only CCD, such as a 7800X3D or 9800X3D, the Processor card now says why there's no CPU Cores choice: every core already has the cache.
- **What slows a game down, in plain sight** — each screen shows the refresh rate it runs at beside the fastest it offers ("240 Hz (max 240 Hz)"). Each GPU shows its PCIe link ("PCIe 5.0 x16") and warns when it has fewer lanes than the card supports, which usually means it's in the second slot or one sharing its lanes with an M.2 drive. The Storage card counts the library games on each drive and points out games on a hard drive, and Game Details says which drive a game is installed on and what kind ("E: · NVMe SSD").
- **Your GPU driver, and whether there's a newer one** — the driver shows the version its maker uses (617.14 for NVIDIA, the Adrenalin release for AMD), its date and how old it is. For NVIDIA, **Check for Newer Driver** asks NVIDIA which Game Ready driver is newest for your exact GPU, desktop or laptop, and offers **Get Driver** when there's a newer one. It only asks when you click, and the request names your GPU model and nothing else. AMD and Intel publish nothing to ask, so their button opens their driver page, where AMD Software and Intel's Driver & Support Assistant take over.
- **Settings, tidied** — each setting now sits with the ones it belongs with. Launch & Performance opens with a new **Launching Games** card: minimize TrayTrigger when a game starts, keep game launchers minimized, and the launch popup, which were all in General. General now has separate **Hotkeys** and **Tools** cards beside Window & Tray Icon. In Library & Art, both free keys are together in one **Art & Info Sources** card, with Refresh All Game Posters and how long game info is kept; Game Titles & Categories keeps title search and auto-categorize; and Library View puts the poster art switch before Show details on hover, which only applies to posters. The Tray Menu's Tools options come after the games options, as the Tools submenu does in the menu. Settings > Diagnostics & Storage has Copy Diagnostic Info and Save Report beside the log, as well as on About. No setting changed, only where it is.
- **DLSS Override for a whole selection** — select games, right-click one, and DLSS Override switches it on for all of them, one game at a time, with the status bar saying which game it's on. It's ticked when every selected game already has it, and then a click switches it off for all of them. When it's done, the status bar names any game that ships no DLSS, isn't installed, or that the driver wouldn't change. It's hidden on a PC with no NVIDIA driver, like the single-game item.
- **A key added later catches your library up** — a SteamGridDB key added once your games are in now fetches their posters as soon as it checks out, where before nothing changed until you found Refresh All Game Posters. That button now also finds posters by name for games that aren't on Steam and have none. And a game added after the key no longer keeps a banner stand-in TrayTrigger had cached for it on an earlier run without one: TrayTrigger now remembers where each poster came from, and gives a banner one more look once there's a key. A RAWG key added later matches your non-Steam games straight away, whether or not auto-categorize is on. A new help page, "SteamGridDB and RAWG keys", walks through getting both.
- **Default scripts get arguments of their own** — Settings > Launch & Performance has a new Default Script Arguments box beside the default scripts, used for every game whose own Script Arguments are empty, so one default like Close Background Apps with "recommended" covers the whole library. A game with Script Arguments of its own passes those instead, and a game's own script never gets the defaults'. Edit Game's Script Arguments box can now be filled in for a game that only runs the default scripts, where before it stayed greyed out until the game had a script of its own, and Edit Game says which arguments the defaults will get.
- **Tools started with games close when your last TrayTrigger game exits** — they no longer wait for a library game you started from Steam or another launcher, which TrayTrigger looked for every 30 seconds.
- **Close Background Apps asks before it closes anything** — the example script now asks each app to close, the way Windows does when you sign out, and an app that won't is left running and named, where before tray apps like OneDrive were ended straight away, mid-sync. Add "force" anywhere in Script Arguments to end the ones that won't close. OneDrive is closed with its own clean shutdown and comes back in the tray. The recommended list is now the cloud sync apps gamers report most, OneDrive, Dropbox and Google Drive; Teams, Slack and Creative Cloud are off it, and you can still name them. It no longer pauses Windows Update when run as Administrator: Windows' Game Mode already holds back driver installs and restart prompts while you play.
- **Start Companion Apps asks too** — the example script that starts SimHub or TrackIR for the games you choose now asks them to close after the game, instead of ending tray programs straight away. One that won't close is left running and named; add "force" to Script Arguments to end it. A program running as Administrator is now reported as one the script can't close, rather than as already closed. For a program you want with every game, Tools does the same job and can close Administrator programs too.
- **A tidier scripts folder** — the two blank templates, _Blank.ps1 and _Blank.bat, are no longer copied into your scripts folder; New script... still makes a new script from them. What they explained, the values TrayTrigger passes in, its environment variables, exit codes and the batch file pitfalls, is now in the folder's README.txt. A script you make with New script... no longer opens with the "DO NOT EDIT THIS FILE" notice meant for TrayTrigger's own copies: it's yours to change.
- **Three example scripts are no longer included** — Save Backup, because TrayTrigger doesn't look after game saves; Wallpaper Engine Pause, because Wallpaper Engine does it better itself: in its Settings > Performance, set "Other application focused" or "Other application maximized" to Pause, which covers borderless games too; and OBS Replay Buffer, because Instant Replay in the NVIDIA App, AMD Software and the Xbox Game Bar already keeps the last minutes of play without a script. If your copy is still as TrayTrigger left it and no game or tool uses it, it's removed from your scripts folder. A copy you've edited, or one a game still runs, is left where it is.

## 1.4.7

- **Back up and restore TrayTrigger** — Settings > Diagnostics & Storage has a new Backup & Restore card. Back Up saves your game library, settings, tools, scripts and artwork to one .zip file; Restore puts them back, to move TrayTrigger to a new PC, after reinstalling Windows, or to undo a change you regret. What you had is backed up first, so a restore can be undone too, and TrayTrigger restarts to finish. Games are found where they are now: through GOG Galaxy, the EA app, Epic or Ubisoft Connect for their games, on the new drive when a drive letter changed, and in your new Windows user folder. A game that isn't installed on the PC is kept, greyed out. Settings that describe the PC rather than your choices (what each tweak found before it was applied, the window's position, Start with Windows) stay as they are. Game saves aren't part of a backup.
- **CPU Cores for Ryzen X3D** — Edit Game > Performance > CPU Cores now offers what fits your CPU: on a 7950X3D, 9950X3D or another Ryzen with 3D V-Cache on one of two CCDs, **3D V-Cache cores** keeps a game on the CCD with the extra cache, where most games run fastest, and **Frequency cores** on the other; on a 7950X or 9950X, **First CCD only**; on an Intel hybrid CPU, performance cores as before. **Auto** picks the right one for the PC the game is played on. TrayTrigger finds the V-Cache CCD from the size of each CCD's cache, so CPUs released later are recognized too, and System > Hardware says what it found. The cores are now set with Windows' CPU Sets rather than a hard affinity mask, which crashed some games and was blocked by anti-cheat, and also for the processes a game starts. For an anti-cheat title that still refuses, set a few seconds to wait after the game starts. The option is hidden on a CPU with nothing to choose, such as a 9800X3D.
- **Suspend and resume a game** — press Ctrl+Alt+P in a game you launched from TrayTrigger to minimize it to the taskbar and freeze it where it is, for a cutscene you can't pause or to step away; press it again and it comes back to the front and carries on from the same frame. Its sound is muted and its playtime clock stops while it's suspended. The tray menu's Now Playing section and the game's right-click menu have Suspend Game and Resume Game, and the PLAYING tag reads PAUSED. Online games disconnect while suspended, and a game protected by anti-cheat (Easy Anti-Cheat, BattlEye and the like) is never suspended. Close Game, Play and exiting TrayTrigger all resume a suspended game first, and if TrayTrigger stops unexpectedly it resumes the game when it next starts. Change or clear the hotkey in Settings > General.
- **Close Background Apps closes a recommended list and can pause Windows Update** — type "recommended" in the example script's Script Arguments and it closes OneDrive, Dropbox, Google Drive, Creative Cloud, Teams and Slack, or add your own names after it. With Script Arguments empty it still does nothing, as before. Tick Run scripts as Administrator and it also pauses Windows Update and Delivery Optimization for the game and starts them again after, so a download doesn't stutter it. It still reopens only what it closed, and never closes your browser, Discord or mouse software unless you name them.
- **Tools can start with your games** — tick "Start when I launch a game" in Edit Tool and a program like MSI Afterburner, SimHub or TrackIR is started just before any game you launch through TrayTrigger, unless it's already running, so it no longer has to start with Windows. Tick "Wait before starting the game" for one that needs a few seconds to get ready, like Afterburner's on-screen display. Tick "Close it when the game exits" as well and it's closed again once your last game has closed, with anything it started as it started up, like Afterburner's RTSS: only the copy TrayTrigger started, never one you opened yourself. A program that runs as administrator asks for permission when it starts and again when it's closed, and the launch popup says which tool the prompt is for. A tool that starts with games shows the Library's controller icon on its card, and they're all together on a new With Games tab.
- **Posters with nothing in the way** — a new eye button beside the view buttons, also in Settings > Library & Art as "Show details on hover", shows each game in Poster Grid and Extra Large as just its artwork. Point at a card, Tab to it or right-click it and the art zooms in within the card, which stays the same size, while the launcher badge, category, title, playtime and Play button fade in. Pick what stays on every card in Settings, from the launcher logo and title to the playtime and the PLAYING tag; out of the box only PLAYING stays, and a game that isn't installed always stays dimmed. Off by default; turn it off again and the cards are exactly as before. With Windows' Animation effects off, the art doesn't zoom and the details appear without fading.
- **Choose the profile new games start on** — games you add used to start on Optimized every time. "New games start on" at the top of System > Performance Profiles now picks Off, Optimized or Aggressive for every game you add from then on; games already in your library keep theirs.
- **A "Favorites First (Recent)" sort** — your favorites at the top, then everything else, each with the game you played most recently first.
- **Clear the library search with one click** — the Library and Tools search boxes have the same x as the Settings search.
- **The Aggressive profile no longer switches off Windows' multimedia scheduler** — after an Aggressive game, TrayTrigger could remove Windows' System Responsiveness setting instead of putting it back. Without it the Multimedia Class Scheduler doesn't start at the next boot, which can stop webcams and audio working in some apps. The setting is never removed now: when TrayTrigger can't tell what it was before, or it was still set from an earlier game TrayTrigger didn't get to finish, Windows' own default goes back, and the same goes for the Games scheduling priority. A PC this has already happened to is repaired after its next Aggressive game.
- **Help where you need it** — more screens have a link to the page about what you're looking at: how titles are detected and how artwork is found in Edit Game, where the info comes from in Game Details, how scanning works in Scan for Games, how Tools work on the Tools page, CPU Cores in System & Performance, and the window, tray icon and hotkeys in Settings > General. Two pages are new: "Writing your own script" and "The window, the tray icon and hotkeys". About lists DLSS Override, Tools and Backup & Restore with the other features, and has a new Online card with the website, online help, a place to ask a question, what's new and the security policy.
- **Polish** — in Compact Icons, the NOT INSTALLED, MISSING and PLAYING tags sit across the foot of the icon instead of being cut mid-word. In the Details list a long title shortens with "…" so the tag and the launcher badge beside it always fit, and the full title shows on hover. Text you type lines up with the placeholder and the drop-downs around it. About > Overview shows your Windows version and data folder in full. The collapsed sidebar's buttons say what they are on hover. System > Hardware counts the cores Windows lists, so an Intel hybrid CPU or one without Hyper-Threading shows the right number. Labels and messages are worded the same way throughout: "poster" for a game's tall image, the tray menu's Recent and Favorites "sections", and "restore" for putting a tweak back.

## 1.4.6

- **Games you've uninstalled are greyed out, not lost** — uninstall a game and TrayTrigger used to go on showing it as if nothing had happened; pressing Play then did nothing useful. Library games are now checked against their own launcher at startup and on every scan, and one that's gone is dimmed and tagged **NOT INSTALLED** (or **MISSING**, for a game you added yourself whose file isn't where you left it). Nothing is removed: your playtime, hotkey, scripts and performance profile are all still there when you reinstall, and the tag clears itself on the next scan. Play still works — for a Steam game it offers to open it in Steam, and for the rest it says which launcher to reinstall from. New "Not installed" and "Executable missing" filters beside the search box list them all, so the ones you won't reinstall can be removed together. A game is only tagged when its launcher was read in full and doesn't list it, so an external drive that isn't plugged in never greys out the games on it.
- **Force Close can no longer touch Windows itself** — when TrayTrigger can't close a game through the process it started, it looks for the game's processes in its install folder. It now never looks in the Windows folder, a drive root, or the top of Program Files, ProgramData or your user folder, and never touches another session's processes or one Windows marks critical. A game whose folder resolved to System32 could otherwise have Force Close end Windows' own processes, which stops the PC with a CRITICAL_PROCESS_DIED blue screen when TrayTrigger runs as administrator.
- **NVIDIA DLSS Override, per game** — games ship with whatever DLSS version was current when they were built and often never update it; your GeForce driver keeps newer ones. Edit Game > Performance now has an **Enable DLSS Override for this game** switch that runs the game on the driver's DLSS files instead, for Super Resolution, Ray Reconstruction and Frame Generation. It is the same setting NVIDIA App calls DLSS Override, and works for games NVIDIA App doesn't list. The card shows the version inside the game and the one it would get (310.1.0 → 310.9.0), and a **Last run** line with the version the game actually loaded the last time you played. TrayTrigger looks through the game's whole folder for its DLSS files, not only beside the file you launch, so games that keep them elsewhere are covered too: every Unreal Engine game does, and so do games started through a small launcher. A game with no DLSS keeps the card as a single line, "Not available. This game doesn't include DLSS.", so you can tell at a glance and a missing card is never mistaken for a fault. Nothing in the game folder is touched, so a game update or "verify files" can't undo it, and if a game ignores it the game simply uses its own DLSS as before. NVIDIA App resets the setting on games it doesn't list; TrayTrigger puts it back each time it launches the game. The card appears on a PC with an NVIDIA driver, and needs no administrator rights.
- **Easy to take back out** — unticking the switch, or **Restore** on the card, returns that game's NVIDIA settings to exactly what they were, and leaves alone anything another tool has changed since. A new **NVIDIA DLSS** card in Settings > Launch & Performance shows how many games have it on and has **Restore All**. Removing a game from the library puts its override back, and so does uninstalling TrayTrigger.
- **NVIDIA's DLSS overlays** — a new opt-in switch on the same Settings card turns on NVIDIA's own on-screen overlays in every DLSS game: the corner line with the DLSS version in use, the preset letter and the render resolution, and, in a game using Frame Generation, the bar across the top with the driver and Streamline versions, the output and motion-vector resolutions, the frame multiplier, your refresh rate and the name of the driver profile the game is running under — which is where an override is written, so it is the one place that confirms which profile took. Both go on together under a single administrator prompt, and unticking puts both back exactly as they were, including a Frame Generation bar you had switched on yourself. It's for checking an override, not for leaving on.
- **DLSS Override without opening Edit Game** — right-click a game and **DLSS Override** is there with the Performance Profile and CPU Cores, ticked when it's on. It says the same thing as the switch in Edit Game because it reads the same record, and switching it on searches the game's folder first, so the status bar says what it's doing. A game that ships no DLSS says so rather than quietly refusing. Hidden on a PC with no NVIDIA driver.
- **Half as many administrator prompts on the Aggressive profile** — launching a game on Aggressive asked permission twice and asked twice again when the game closed. The two machine-wide settings it changes are now written together, so it's one prompt when the game starts and one when it ends. Turning on Defender Exclusion still adds one of its own each way, because Windows Defender can't be changed in the same step.
- **The Tools page answers the keyboard like the library** — Ctrl+A now selects every tool on the page, and Ctrl+A, Delete, Esc and Ctrl+F all work wherever you clicked last, instead of only after clicking a tool. Ctrl+A had never worked at all, though the help said it did. Esc now clears the selection first and the search second, as it does in the library.
- **Script templates and examples stay up to date** — the blank templates and five examples in your scripts folder were only ever written when they were missing, so a correction to one reached new installs and nobody else. TrayTrigger now replaces its own copies when it has a newer one. If you had edited a file, your version is kept beside it with ".previous" on the end rather than lost, and a script of your own is never touched. The examples no longer ask to be edited in place either: the OBS example takes the path to OBS as a Script Argument, so a Steam copy of OBS needs no editing at all. Two examples are renamed for what they do — Quiet Mode is now Close Background Apps, and Companion Apps is Start Companion Apps.
- **Close Game instead of End Session** — the End Session action left the game running and only put the tweaks back, which read as if it closed the game. It's now **Close Game**, in the game's right-click menu, Game Details and the tray's Now Playing menu: it asks the game to quit the way its own close button does, and the tweaks are restored once it has. A game that won't close (one asking whether to save, say) is left open and TrayTrigger tells you; Force Close is still there for that.
- **Search from the tray** — the tray menu now opens with a search box at the top: type a few letters of a game's name or category and the menu narrows to the matches; Enter launches the top one, Esc clears the box. It works with grouped or flat menus, compact or normal, and finds tools too when they are in the menu. Don't want it? Turn off "Show a search box at the top of the tray menu" in Settings > Tray Menu.
- **Open the tray menu from the keyboard** — Ctrl+Alt+T opens the tray menu by the tray icon, where a right-click opens it, from anywhere in Windows, with the search box ready, so a game is a few letters and Enter away. Press it again to close the menu. Change or clear it in Settings > General, which now has both TrayTrigger shortcuts: Ctrl+Alt+G for the window and Ctrl+Alt+T for the tray menu.
- **No white flash when the window comes back** — showing the window again from Ctrl+Alt+G or the tray menu no longer shows an empty white box for a moment before it's drawn.
- **Edit Game has tabs** — All, Identity & Library, Launch, Performance and Scripts, like Settings and System. It still opens on All, looking as it did; the other tabs show one card each, keep your unsaved edits when you switch, and Ctrl+Tab moves between them. If Save refuses a value on a card you can't see, the dialog switches to it and puts the cursor in the field. Working Directory and Launch Arguments now sit under "Advanced launch options", which opens by itself when either has a value, and the Performance card lists exactly what the chosen profile will change for that game.
- **A selection bar** — select games with Ctrl+click, Shift+click or Ctrl+A and a bar appears over the bottom of the library: how many are selected, Add to Favorites, Change Category, Hide, More (the full right-click menu) and Clear. Tools get the same bar when two or more are selected. Right-click still works as before.
- **Clearer tweak wording** — "Reset Defaults" is now **Restore Previous Settings**, and each tweak's "Revert to Default" is **Restore Previous**, because they put back what your PC had before TrayTrigger changed it, which isn't always the Windows default. The restore-point tag reads "Restore point before changes: On/Off", and after a preset or a restore the status line says whether a restore point was actually made.
- **More time to undo** — removing a game can now be undone for 10 seconds instead of 6, and the countdown stops while your pointer is on the Undo toast or it has keyboard focus. Removing a scan location, an ignored game or an ignored folder in Settings can now be undone the same way.
- **Easier to read** — grey hints and labels are brighter, no ordinary text is smaller than 11 px any more (only the small status tags stay compact), and tooltips are dark like the rest of the app and wrap. The view buttons, the OPT-IN, RESTART and ADMIN tags, and Close Game and Force Close now explain themselves on hover.
- **Better from the keyboard** — Esc cancels and Enter confirms in every dialog; in Edit Game and Edit Tool, Esc asks before throwing away changes you haven't saved, and the hotkey box still records Esc and Enter while it's listening. Tab now shows a blue ring on every button, tab, sidebar entry, drop-down and list row (a mouse click still shows none). Tab and the arrow keys no longer get stuck on the first poster card, and the arrows move between cards by row and column. Hold Alt in a dialog for its button shortcuts: Alt+S saves in Edit Game and Edit Tool, Alt+C cancels.
- **Better with a screen reader and reduced motion** — every icon button, text box and drop-down now has a name Narrator can read ("Add Game", "Launch arguments", "Play Cyberpunk 2077"), and each System & Performance tweak reads as one line, such as "Optimize: Windows Game Mode, standard, needs a restart". With Windows' Animation effects turned off, posters no longer grow on hover and the launch card by the tray appears without fading.
- **NOT INSTALLED keeps its first word** — on a poster card, moving the pointer over an uninstalled game brought out the favourite star, which pushed the **NOT INSTALLED** tag off the edge of the card and left it reading **INSTALLED** — the opposite of what it means. The tag now sits on its own line under the others, where nothing crowds it.
- **Smaller improvements** — a shorter welcome screen, whose second button now says "Skip for now"; Close Game and Force Close in Game Details while the game is playing; resizable "Choose Game Executable" and "Change Match" windows; an arrow and a fade instead of a scrollbar when the category tabs don't fit; consistent tags for fixed and live values on the hardware cards, with a drive more than 90% full shown in the warning colour; the status bar's hotkey reminder only for your first five sessions (after that, point at the tray icon); and the sidebar open on a fresh install (existing users keep theirs).
- **Tidier in a small window** — at TrayTrigger's smallest size, the Details list now shortens a long game title with "…" instead of cutting it mid-word and slicing the tag beside it, the Settings tabs scroll behind the same arrows the library's category tabs use so the search box beside them stays put, and System & Performance's "Performance Optimization Status" heading no longer runs under the buttons next to it.

## 1.4.5

- **Safer elevated actions** — the Defender exclusion, System Restore point and "needs administrator" tweaks now start Windows' own tools by their full path, lock the temporary registry file until Windows has read it, and handle folders with a curly apostrophe in the name (Assassin’s Creed), which used to make the Defender exclusion fail.
- **Stricter update checks** — each release's checksum file is now signed, and from this version on TrayTrigger only installs an update whose checksums carry that signature, so tampering with a release on GitHub is not enough to push an update. The installer must also be the one named for that release, and it is checked again at the moment it is started.
- **Safer imports** — a dropped shortcut whose icon points at a network share or web address no longer has that address opened, a hand-edited games.json can't name cache files outside TrayTrigger's own folders, and artwork downloads have a size limit.
- **Playtime counts when TrayTrigger closes first** — quitting TrayTrigger (or signing out) while a game is still running now records the time played so far instead of losing the session.
- **Tidier menus and dialogs** — the tray menu and every right-click menu use the same thin separator, a favorite is no longer listed a second time under Recent, and tray icons are all the same rounded square. Checkboxes match the dark theme, Edit Game shows the game's name as its heading and loses its minimize and maximize buttons, unplayed games say only "Never played", and the status bar stays empty until there is something to report.
- **Game scripts** — batch scripts no longer have a percent sign in the game's path expanded by Windows, a game whose name starts with a dash no longer breaks a PowerShell script, and a post-exit script run because TrayTrigger is closing is told the real playtime instead of 0.

## 1.4.4

- **Tools, for the programs you use alongside games** — a new optional Tools page for things like DLSS Swapper, Vortex or MSI Afterburner. Turn it on in Settings > General (it's off by default), then drop a program or its shortcut on the page. Tools get their own categories, favorites, batch editing (select several to change their category, favorite or Run as administrator at once), sort order, three views (large icons, small icons, list), hotkeys and the same launch popup as games, with none of the game features: nothing is scanned or looked up, and no profile, scripts or playtime. "Run as administrator" is a checkbox that lets Windows ask for permission as usual, and a shortcut's own setting comes across. An optional Tools submenu in the tray menu has its own sort order, under Settings > Tray Menu. Microsoft Store apps like Xbox work too: click Browse Apps next to Add Tool and drag the app onto the page. Scripts (.bat, .cmd, .ps1) can be tools as well, with an option to run them with no window.
- **Launch notice stays up long enough to read** — pressing Play, a game's hotkey or a tray menu entry now shows the "Launching..." notice or launch popup for 2 seconds before the game starts, up from under a second, so a game that goes fullscreen straight away no longer covers it before you see it.

## 1.4.3

- **Search in Settings, About and System & Performance** — a search box sits beside the tabs: type a word ("hotkey", "HDR", "log") and the tab you're on keeps only the cards that mention it, with the word highlighted and the first match scrolled into view. All searches every section, and the search stays as you switch tabs. Ctrl+F jumps to the box; its x or Esc clears it.
- **A launch popup for hotkey and tray launches** — starting a game from its hotkey or the tray menu while TrayTrigger is hidden used to show nothing until the game appeared. A small card near the tray clock now shows the game, what it's waiting for (Battle.net signing in, for example), and closes once the game starts. It never takes focus and clicks pass through it. If the launch fails, the reason shows there instead of in a dialog nobody could see, with a link to open TrayTrigger. Turn it off, or have it show on every game launch, in Settings > General > Window & Tray Icon.
- **Launchers stay minimized while your game starts** — new "Keep game launchers minimized when launching a game" option in Settings > General > Window & Tray Icon, on by default. Steam starts minimized to the tray when it isn't already running (before, only for games set to close the launcher after exit), GOG Galaxy starts in the background when it isn't already running, and Epic keeps its silent launch. The EA app and Ubisoft Connect have no way to start quietly, so they're left as they are.
- **Games come to the front sooner** — a game started through its launcher (EA app, Ubisoft Connect, GOG Galaxy, Epic, Xbox, Battle.net) could open behind TrayTrigger for several seconds while TrayTrigger confirmed it was the game. It now gets focus as soon as its window appears. With "Minimize to system tray when launching a game" on, TrayTrigger also hides as soon as the game is launched instead of waiting for its window, and the launch popup shows the launch in its place.
- **System & Performance reads more clearly** — tweak groups and profiles have proper headings with a count ("8 tweaks · 6 optimal"), the sections say which settings are always on and which apply per game while it runs, groups are named for what's in them (Display & Input, Network & Background Activity, Security), and the power plan that appears in both is labelled "(always on)" or "(profile)". Every tweak now has one name, the same on the page as on its Learn more page; Windows Gaming Utilities waits for the specs to load, and the "Live Hardware Telemetry" label only shows where the live readings are.
- **TrayTrigger looks like TrayTrigger** — the name is written with "Trigger" in the logo's blue in the sidebar, About and the welcome screen, and the app icon now greets you on an empty library and in the update prompt.
- **Xbox games whose files are gone are no longer imported** — when an Xbox app game's folder is deleted or its drive is removed without uninstalling the game, Windows still lists it as installed. Scan for Games used to import those with no icon, and Play only brought up the Xbox app's "can't be found" error after applying the game's performance profile. They're skipped now, and one already in your library says it's no longer installed as soon as you press Play. Open Containing Folder opens an Xbox game's real folder, and no longer lands in Documents for one whose files are gone.
- **Settings, System and About tabs jump to the top** — picking a tab (or clicking the one you're on) now starts at the top of that section instead of wherever you'd scrolled to. Section headings now use the same names as their tabs.
- **Empty Favorites and empty library say so again** — the Favorites tab with nothing starred, and a brand-new library, showed a blank box instead of "No favorites yet" or the Scan for Games prompt. Broken since 1.3.7.

## 1.4.2

- **Battle.net library integration** — Scan for Games now finds games installed through Battle.net (World of Warcraft, Overwatch, Diablo, Hearthstone, StarCraft, Call of Duty and the rest) on any drive, with their real titles, and launches them through Battle.net. If Battle.net is closed, TrayTrigger starts it and keeps asking until the game opens, so one click works even while Battle.net is still signing in. Each game's launch code is read from Battle.net itself and saved, so there's no list to go out of date.
- **Better game names from folders** — titles written without spaces (BALLxPIT), acronyms run into a word (ACBlackFlag), packaged Unreal games (Gothic 1 Remake, Persona 3 Reload), and folders with an extra trailing word now match the right game.
- **Tray menu** — game icons now show on the first open after startup (they used to appear only after a launch). Rows are tighter, in line with the app's own menus, and a game with no icon shows its launcher's logo instead of a generic controller. New in Settings: turn icons off, a compact layout for a long library, and left-click on the tray icon to open the game menu instead of the window.
- **Hotkeys are recorded, not typed** — click the hotkey box in Edit Game or Settings and press the keys. A combination another game, the window hotkey, or another app already uses is refused on the spot with the reason, instead of being saved and quietly never working. Shortcuts Windows itself needs (Alt+F4, Alt+Tab, Win+anything) are refused too, and a single modifier plus a letter (Ctrl+S) gets a warning first, since it would stop that shortcut working in every app.
- **A diagnostic report worth attaching** — About > Copy Diagnostic Info now reports the install type, Windows build, CPU, GPU and RAM, each launcher's integration and whether its client is installed, library counts by platform, the settings that matter to bugs, applied tweaks, any running session, and the last warnings from the log. API keys are never included. Save Report... writes the same as a file.
- **Settings regrouped by what things do** — General has one Window & Tray Icon card (startup, minimize on launch, the icon, left-click, the show/hide hotkey); the Library tab's Scan for Games card holds the scan button, auto-scan on startup, scan locations and ignored games together; the Tray Menu card is split into what it lists and how it looks.
- **Edit Game reads top to bottom** — four cards instead of six: Identity & Library (title, category, hidden, store link), Launch (which client starts it, then the path, folder, arguments, Run as Administrator and hotkey), Performance, and Scripts. The launcher options that used to sit at the bottom now come first, above the fields they govern.
- **"Always show icon in tray" now takes** — the request is retried while Windows is still registering the icon, the icon is re-added so Windows picks the change up without an Explorer restart, and Settings shows what Windows did with it instead of saying nothing.
- **Right-click menus show their state** — the Performance Profile tier, CPU Cores choice, Run as Administrator and Close Launcher After Game Exits carry a check mark for the current setting, for one game or a selection. The game you right-click stays highlighted while its menu is open.
- **Ignore a folder** — Settings > Game Scanner can now keep a whole folder out of every scan (a Utilities, Mods or emulator folder inside a scan location), and the Ignored Games list is always shown so you can see what's excluded.
- The Steam and Battle.net client folders are no longer offered as games when a scan location contains them, or when one of them is dropped on the window.
- Game names no longer keep ®, ™ or © ("Overwatch®" is now "Overwatch"). Names already in your library are cleaned the next time TrayTrigger starts.
- **EA app is detected again** — the EA app registers its launch handler without quotes around its path, and TrayTrigger only read the quoted form, so it reported the EA app as not installed and launched EA games by their own exe instead of through the client (no EA sign-in, no cloud saves). Both forms are read now.
- Force-closing a Battle.net game that was moved with Battle.net's own Move Install now finds it, and a Battle.net game that has been uninstalled says so instead of quietly doing nothing.
- Titles containing "Steam" or "GOG" ("Steam Tactics", "Full Steam Ahead") are no longer searched with that word removed; it's only dropped as a trailing store tag ("Portal.2.Steam").

- **Library filters** — a filter flyout beside the sort box narrows the library by launcher, performance profile, and state (never played, favorite, missing executable, has a hotkey, has scripts, runs elevated). A count badge shows how many filters are active, and an empty result explains itself instead of looking like an empty library.
